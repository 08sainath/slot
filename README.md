# SLOT movie booking demo

## Run locally
1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

To production-build: `npm run build`, then `npm start`.

All movie/theatre/showtime data is illustrative. Seat selections are stored in browser localStorage. No payments, real ticket issuance, or backend persistence are implemented. Replace demo catalogue and add a database/API before production.

# SLOT — Movie Tickets (Demo)

Premium dark-themed booking demo built with Next.js App Router, TypeScript and Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

All movies, venues, prices, schedules and seat states are illustrative. No real payment is collected and no real ticket or reservation is issued. The admin screen is a UI demo only and does not persist data.
