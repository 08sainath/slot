# SLOT — Movie Tickets (Demo)

Premium dark-themed booking demo built with Next.js App Router, TypeScript and Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

All movies, venues, prices, schedules and seat states are illustrative. No real payment is collected and no real ticket or reservation is issued. The admin screen is a UI demo only and does not persist data.
